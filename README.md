# CivicLens

# 🏛️ Civic Issue Accountability Platform

A MERN-based web platform that allows citizens to report civic issues, enables community-driven prioritization, and ensures transparent resolution by government officials.

---

## 📌 About the Project

The Civic Issue Accountability Platform is designed to address a common real-world problem where civic complaints are often ignored, delayed, or lack visibility. This platform ensures that every reported issue remains public until it is resolved, creating accountability through transparency.

Citizens can report issues anonymously, track their progress, and collectively highlight high-impact problems, while government officials can officially claim, update, and resolve issues through a secure portal.

---

## 🚀 Features

- Citizen issue reporting with title, description, category, image, and location
- Anonymous reporting with auto-generated unique token number
- Community voting using “Yes, I face this problem too”
- Automatic priority calculation based on votes and unresolved duration
- Public issue cards with color-coded status:
  - 🔴 Pending
  - 🟡 In Progress
  - 🟢 Resolved
- Detailed issue view with timeline and official updates
- Separate government portal with role-based access
- Government announcements and schemes posting
- Dashboards with filters and city-wide heatmaps
- Multi-language support (English + Telugu)

---

## 🧑‍🤝‍🧑 User Roles

**Citizens**
- Login using personal email IDs
- Report and track civic issues
- Vote and view government updates

**Government Officials**
- Login using verified official email IDs
- Claim and manage reported issues
- Update status and publish announcements

---

## 🧠 Tech Stack

- Frontend: React
- Backend: Node.js & Express
- Database: MongoDB
- Maps: Google Maps / OpenStreetMap
- Authentication: Role-based email authentication
